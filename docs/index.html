A backup, or a connected device?

Different tasks use different sources. Phosphor gives you tools for both.

Ready for your Mac.

Requires macOS Sonoma 14 or later. Install Phosphor, add the device tools, then connect your iPhone or iPad.

Install with Homebrew

The tap installs Phosphor and the libimobiledevice fallback.

brew tap momenbasel/phosphor
brew trust --tap momenbasel/phosphor
brew install --cask phosphor

The trust command is for Homebrew 7 and later. Review the tap source before trusting it.

Or download the app

Open the disk image and drag Phosphor into Applications.

Add the device tools

For the primary device backend, install pymobiledevice3. Phosphor checks for available tools when it launches.

brew install pipx
pipx install pymobiledevice3

Before you connect.

Does Phosphor need an iCloud account?

No. Phosphor works with local device backups. Connect an unlocked device, approve the Trust prompt, and create a backup on your Mac.

Can I open an existing encrypted backup?

Yes, with its backup password. Phosphor supports encrypted local backups made by Finder and other compatible tools. The password stays in memory for the session unless you choose to save it in macOS Keychain.

Why isn't my iPhone detected?

Check that your device is unlocked, the USB cable supports data, and you have approved Trust on the device. Make sure pymobiledevice3 is installed, then relaunch Phosphor. See the troubleshooting guide for backend and connection checks.

Can I recover files that aren't in a backup?

Backup browsing shows data contained in the selected backup. It cannot recover files that were never included. Available data and live-device tools depend on your iOS version, device permissions, and backup contents.

Read the documentation, report a problem, or follow the contribution guide. Phosphor is released under the MIT license.
